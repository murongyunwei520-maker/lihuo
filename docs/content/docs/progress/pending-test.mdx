# Pending Tests

- Site error cards fail fast: when the site replies with a generic failure card (Dola: 「出了点问题，请稍后重试。」), the task must fail within seconds with that wording — not sit until the 3-minute "request not accepted" fallback. Those cards carry no body text and no player, so a regression here shows up as a long wait plus a generic message.

- Short drama studio (new page, top nav 「短剧工作室」 / `/drama`): opening it on a fresh browser profile should seed one sample episode instead of hanging on 「正在读取本地数据…」. The left panel is the script-first entry: paste a script or upload a `.txt`/`.md` file (≤200KB) and the script panel shows it; a non-empty draft must enable the 「拆解成分镜」 button immediately. Check both light and dark themes. The rule-based split path involves no network request and no account quota.
