- Short drama generation runs one item at a time on purpose: 全部生成 / 全部出图 / 全部配音 are serial (one image or one clip at a time) and never auto-retry. Raising concurrency, adding retry/backoff, capping batch size and total timeout, limiting how much media stays in local storage, and keeping the idempotency-key rule consistent are all still open — confirm the numbers with the user before changing any of them.
