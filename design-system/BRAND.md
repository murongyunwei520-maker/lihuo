# BRAND.md · 离火品牌视觉规范

品牌资产只有一个出处：`web/src/constant/app.ts` 的 `APP_BRAND`。任何页面不得再写死应用名。

---

## 1. 品牌核心

| 项 | 值 | 来源 |
|---|---|---|
| 中文名 | 离火 | `APP_BRAND.name` |
| 英文名 | Lihuo | `APP_BRAND.nameEn` |
| 标语 | 以火为笔，炼万象 | `APP_BRAND.tagline` |
| 一句话定位 | 面向 AI 创作的无限画布工作台 | `APP_BRAND.description` |
| 命名空间 | `lihuo` | `APP_BRAND.namespace` / `STORAGE_NAMESPACE` |
| 标志 | 朱雀展翼剪影（单色，`currentColor`） | `web/public/logo.svg` |

**名字的解法**：离火取自《易》"离为火"，是火之象，也是"附丽、文明"之象。这决定了品牌不是"燃烧、激烈、爆炸"的火焰红，而是**火在纸上的余温**——所以视觉落点是雾紫、宣纸、留白，而不是橙红渐变。这条解释必须写进任何对外介绍，避免团队各自理解。

---

## 2. 双色哲学：火为意，紫为气，蓝为信

| 层 | 色 | 承担的叙事 |
|---|---|---|
| 意 | 火（暖色，极小面积） | 创作的冲动、朱雀的意志。只出现在标志、点睛状态、极少量强调 |
| 气 | 雾霭紫（主色） | 整体氛围与品牌识别。占绝对主导，是"离火看起来是什么样"的答案 |
| 信 | 冰川蓝（信息色） | 结构、连接、数据、可信。表达"系统在运转"，不表达情绪 |

暖色使用总量**不超过界面面积的 2%**。它出现在：标志本身、品牌渐变里的高光、极少数"新/热"标记。**不做暖色按钮、暖色大标题、暖色背景块。**

---

## 3. 标志使用

### 规格

| 项 | 规定 |
|---|---|
| 源文件 | `web/public/logo.svg`（64×64 viewBox） |
| 着色 | 单色 `currentColor`，随文字色继承。**不改色、不加渐变、不加描边** |
| 最小尺寸 | 界面内 16px；独立展示 24px；favicon 16px |
| 安全边距 | 四周至少留 1/4 标志宽度的空白 |
| 背景 | 亮色用 `#1a1526`，暗色用 `#ece7f7`；彩色背景上必须为单色高对比 |

### 禁止

- ❌ 拉伸变形（必须等比）
- ❌ 加投影、外发光、描边、圆角容器包边
- ❌ 换色成橙红"火焰色"
- ❌ 在标志上叠加文字或图形
- ❌ 用低分辨率位图替代 SVG

### 组合

标志 + 文字时，横向排列，间距 = 标志宽度的 1/2，基线对齐文字中段。中文用「离火」，英文用「Lihuo」，不同时出现中英双名（除非页脚版权行）。

## 4. 品牌肌理与图形语言

已有实现，直接复用，不新增：

| 工具类 | 效果 | 允许用在哪 | 禁止用在哪 |
|---|---|---|---|
| `.lihuo-grain` | 宣纸颗粒（`feTurbulence`，opacity .15，`mix-blend-mode: overlay`） | 首页深色区块、空态插画底、品牌页 | 画布、面板、表格、任何需要读文字的区域 |
| `.lihuo-brand-text` | 雾霭紫渐变文字（`#efe9fb → #c4b8ef → #9b8ad0`） | 首页主标题的一两个词 | 正文、按钮、表格、状态文字 |
| `.lihuo-brand-bg` | 紫渐变底色 | 品牌条、启动页 | 卡片、面板、表格行 |
| `.lihuo-marquee` | 关键词横向流动（hover 暂停，reduced-motion 停止） | 首页关键词带 | 产品界面任何位置 |

图形语言三条：

1. **线条极细**（1px），不用粗描边。
2. **圆角克制**（8–18px），不用大圆角胶囊承载信息。
3. **留白大于装饰**。同一屏装饰性元素不超过 1 个。

## 5. 文案语气

| 原则 | 做法 |
|---|---|
| 短 | 按钮 ≤ 4 字，标题 ≤ 12 字，说明 ≤ 2 行 |
| 动作导向 | 用动词开头："生成图片"、"连接账号"，不用"图片生成功能" |
| 说人话 | "额度用完了"而不是"配额校验未通过" |
| 不夸张 | 不用"极致""颠覆""一键封神"，不用感叹号 |
| 出错时给下一步 | "登录已失效，请重新扫码"而不是"操作失败" |
| 不装可爱 | 不用"哎呀"、"~"，不用表情符号（除非用户明确要求） |

### 术语表（全站统一，不得混用同义词）

| 概念 | 统一叫法 | 不要叫 |
|---|---|---|
| 无限画布 | 画布 | 白板、看板、canvas 页面 |
| 画布元素 | 节点 | 卡片、模块、block |
| 模型参数 | 参数面板 | 设置面板、属性面板 |
| 豆包 / Dola 账号集合 | 账号池 | 账号列表、号池（对外文案） |
| 本地浏览器桥接服务 | 桥接（Bridge） | 插件、代理、服务端 |
| 生成任务列表 | 任务中心 | 队列、日志页 |
| 管理员功能集合 | 管理后台 | 后台系统、admin 面板 |

## 6. 品牌露出位置

只有四处允许出现品牌强表达，其余位置保持中性：

1. **首页首屏**：标志 + 标语 + 品牌渐变文字 + 宣纸肌理。
2. **启动 / 加载页**：标志淡入，≤ 800ms，不播放完整动画。
3. **关于 / 版本弹窗**：标志 + 名称 + 版本号 + 开源出处。
4. **空态插画**：可用标志的局部线条做极简构成，不新画插画角色。

侧边导航、页头、表格、画布工具栏**不放标志**，只放文字或图标。

## 7. 品牌相关改动清单

品牌化只允许改这几处（与 `AGENTS.md` 一致）：

- `web/src/constant/app.ts` → `APP_BRAND`
- `web/index.html` → `<title>`、`meta description`、favicon
- `web/public/logo.svg`
- `web/src/i18n/locales/*` → 品牌相关文案
- `design-system/BRAND.md` → 本文件

**不要**在业务组件里写死应用名、标语或标志。需要时读 `APP_BRAND`。

---

## 8. Do / Don't

**Do**

- 用 `text-foreground` / `text-muted-foreground` 让标志与文字自动适配主题。
- 品牌页用宣纸肌理 + 大留白建立"纸与火"的气质。
- 对外介绍里解释"离火"的出处，统一团队认知。

**Don't**

- ❌ 把品牌色做成橙红火焰渐变。
- ❌ 在画布或后台大面积使用品牌渐变。
- ❌ 给标志加任何效果。
- ❌ 自创第二套品牌口号或英文名。
