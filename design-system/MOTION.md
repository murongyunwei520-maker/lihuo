# MOTION.md · 交互动效规范

离火是工具型产品，动效的唯一职责是**让因果可见**：谁触发的、进行到哪、结果落在哪。不做表演性动效。

---

## 1. 四条原则

1. **跟手优先。** 拖拽、缩放、平移**零过渡**，必须 1:1 跟随指针。任何这里加缓动都是 bug。
2. **因果可见。** 状态变化要显示"从哪来、到哪去"，而不是突然替换。
3. **短。** 单次 UI 过渡不超过 **240ms**；超过 300ms 的过渡一律视为错误。
4. **可降级。** 尊重 `prefers-reduced-motion`，关闭位移与循环动画，保留透明度与状态切换。

---

## 2. 时长表（唯一标准）

| 类型 | 时长 | 说明 |
|---|---|---|
| hover / press 反馈 | 100ms | 背景、颜色、轻微位移 |
| 图标切换、开关 | 140ms | 位置或形态变化 |
| Tab / 分段控件指示条 | 180ms | 指示条滑动 |
| Popover / Dropdown / Tooltip | 160ms 进 / 120ms 出 | 缩放 + 淡入 |
| Modal | 200ms 进 / 160ms 出 | 淡入 + 上移 8px |
| Drawer | 240ms 进 / 180ms 出 | 侧滑 24px + 淡入 |
| 节点生成完成出现 | 240ms | 淡入 + 从 0.98 放大 |
| 画布拖拽 / 缩放 / 平移 | **0ms** | 完全跟手 |
| 循环指示（呼吸、扫描） | 1200–1600ms/周期 | 只用于"进行中" |

---

## 3. 缓动

```css
--ease-out-quiet: cubic-bezier(0.2, 0, 0, 1);   /* 进场、状态推进（默认用这个） */
--ease-in-quiet:  cubic-bezier(0.4, 0, 1, 1);   /* 退场 */
--ease-standard:  cubic-bezier(0.4, 0, 0.2, 1); /* 位移类，如抽屉 */
```

- **默认全部用 `ease-out-quiet`。** 进场快、收尾稳，符合"界面后退"的气质。
- **禁止 bounce / elastic / 回弹。** 工具型产品里的弹跳会被读成"卡了一下"。
- **禁止线性缓动**做 UI 过渡（只有进度条填充与骨架屏扫描可用线性）。

---

## 4. 位移与缩放幅度

| 元素 | 位移 | 起始缩放 | 透明度 |
|---|---|---|---|
| Tooltip | 4px | — | 0 → 1 |
| Popover / Dropdown | 6px | 0.97 | 0 → 1 |
| Modal | 8px（上移） | 0.98 | 0 → 1 |
| Drawer | 24px（侧向） | — | 0 → 1 |
| 节点完成出现 | 0 | 0.98 → 1 | 0 → 1 |
| 列表项新增 | 0 | — | 0 → 1 + 高度展开 |

超过 24px 的位移一律不允许。

---

## 5. 画布专项（最容易做错的地方）

| 行为 | 动效规定 |
|---|---|
| 拖拽节点 | 无过渡、无阴影变化；拖拽中只提升 `z-index` 与 1px 描边 |
| 框选 | 选框实时跟随，松手后不做"收缩动画" |
| 缩放 | 滚轮缩放即时生效，不做缓动追赶；缩放中隐藏文字级细节（LOD） |
| 平移 | 空格 + 拖拽，零延迟 |
| 节点连线 | 拖拽中贝塞尔路径实时重绘；松手吸附靠 1px 描边高亮，不做磁吸弹跳 |
| 面板展开/收起 | 180ms，宽度过渡而非位移，避免节点跳动 |
| 右键菜单 | 120ms 淡入，出现在指针右下 8px，超出视口自动翻转（不播放"翻转动画"） |
| 生成中节点 | 描边呼吸（opacity 0.5 ↔ 1，周期 1400ms），**不闪烁、不旋转整个节点** |
| 生成完成 | 结果淡入 240ms + 描边回到常态；**不弹 toast 抢占注意力**，只在任务条计数 |

**性能红线**：画布拖拽必须 ≥ 55fps。高频状态（拖动坐标、缩放系数）留在组件本地 state 或 ref，不得在每帧写入全局 store 触发全树重渲染。

---

## 6. 异步与长任务反馈

生成类操作是离火的核心，反馈必须分三段：

| 阶段 | 时间 | 表现 |
|---|---|---|
| 已提交 | 0–300ms | 按钮进入 loading，节点出现占位骨架 + "排队中" |
| 进行中 | 300ms 起 | 节点描边呼吸 + 模糊进度（"约 1–2 分钟"），任务条计入运行数 |
| 完成 / 失败 | — | 结果就地落位（240ms 淡入）；失败显示站点原文 + 重试按钮 |

规则：

- **不使用百分比假进度。** 拿不到真实进度时用不定式呼吸或阶段文案（"上传参考图 → 生成中 → 下载产物"）。
- **不叠加双层加载。** 节点已有骨架时，不要在页面上再弹一个全局 loading。
- **超过 30 秒必须有可中断入口**（取消任务）。
- **失败不弹窗。** 错误就地显示在节点内，保留用户输入。

## 7. 参考映射（来自 60fps.design）

以下案例来自 `60fps.design` 的公开 shot 列表。**时长为离火反推值，非站点官方参数**，仅作方向校准。

| 参考 shot | 可学的点 | 离火落点 | 反推时长 |
|---|---|---|---|
| Revolut · Card Ready Animation | 完成时的"确认感"：一次短促的收束，而非长时间庆祝 | 节点生成完成 | ~240ms，单次 |
| Revolut · Create / Delete Pocket | 新增与删除的对称性，删除不做"消失"，做"收回" | 节点删除、面板项移除 | 180ms |
| Runmo · Drag to Adjust Distance Wheel | 拖拽数值时，视觉与数值同步无延迟 | 参数面板滑杆、画布缩放 | 0ms（跟手） |
| Runmo · Distance Wheel Fill | 环形/线性填充的连续性，不跳格 | 额度、进度指示 | 线性，填充连续 |
| Duolingo · Battery Fill Up | 进度填充配合轻微"到位"反馈 | 任务进度条 | 填充 600ms + 到位 120ms |
| Duolingo · Sparkle Pop | 微小元素出现的弹性质感（离火不采用弹性） | 仅参考其"轻"的幅度 | 不采用 |
| CRED · Ticket Pop on Slider | 值变化时的元素替换方式 | 参数值切换的标签替换 | 140ms |
| Threads · Splash Logo Animation | 品牌动效的克制程度 | 启动页 / 首页 Logo 呼吸 | 品牌动效允许 600ms，仅首页 |
| Circle · Bottom Sheet Open | 抽屉的层级与背景处理 | 画布底部任务栏、抽屉 | 240ms |
| Platen · Typewriter Intro | 打字机节奏不可过快 | Agent 流式输出的节奏感 | 流式，无额外动效 |

**不可学**：Splash 长时间动画（启动超过 800ms 即为缺点）、整页视差滚动、粒子/霓虹特效。

## 8. 技术实现约定

| 场景 | 用什么 |
|---|---|
| hover、颜色、简单位移 | **CSS transition**（首选，成本最低） |
| 进出场（挂载/卸载） | CSS + `tw-animate-css`（已在依赖中） |
| 需要编排、手势、布局动画 | `motion`（已在依赖中，v12） |
| 循环呼吸 | CSS `@keyframes`，必须包在 `prefers-reduced-motion` 保护内 |
| 画布拖拽 | 直接写 `transform`，不走动画库 |

- **不新增动画依赖。** 现有 CSS + `tw-animate-css` + `motion` 已覆盖全部需求。
- 动画只用 `transform` 与 `opacity`。禁止动画 `width` / `height` / `top` / `left`（布局抖动）。
- 进场动画必须能被中断（快速重复触发时不排队、不叠加）。

---

## 9. 降级

```css
@media (prefers-reduced-motion: reduce) {
    /* 移除位移动画与循环动画，保留 opacity 与颜色过渡 */
}
```

已有实践：`globals.css` 的 `.lihuo-marquee-track` 在 reduced-motion 下停止动画，新动效沿用同一模式。

---

## 10. Do / Don't

**Do**

- 用 100ms 的底色变化表达 hover，而不是缩放整个按钮。
- 用描边呼吸表达"还在生成"，而不是转圈图标 + 文字双重提示。
- 让结果落在用户操作的位置（节点上），而不是页面角落。

**Don't**

- ❌ 给画布拖拽加 `transition`。
- ❌ 用弹跳/回弹缓动。
- ❌ 用骨架屏 + 全局 loading + 按钮 loading 三层同时出现。
- ❌ 假百分比进度条。
- ❌ 超过 240ms 的 UI 过渡。
- ❌ 用动画掩盖加载慢（动画只会让等待感更长）。

---

## 11. 沉浸式工作室环境动效

用户页仙境背景允许 18–36 秒的慢速环境循环，仅用于云雾、光带、星尘、花瓣与人物极轻微浮动；此例外不改变 UI 过渡不超过 240ms 的规则。

- 环境动画只改 `transform` 与 `opacity`，粒子数量固定且使用 GPU 合成，不在每帧写 React state 或全局 store。
- 鼠标视差通过 `requestAnimationFrame` 写 CSS 变量，背景、人物与窗口使用不同的小幅系数，不拦截指针事件。
- 卡片悬浮与按钮高光保持短反馈；不得让人物形变、五官模糊或遮挡交互控件。
- `prefers-reduced-motion: reduce` 下关闭视差、浮动、粒子、光带与错峰位移，仅保留即时可读静态画面。
