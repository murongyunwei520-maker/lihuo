# components/admin-console.md · 管理后台（含用户管理）

> 覆盖：后台外壳、导航、列表页、详情页、表单页、权限态、危险操作
> 代码：**无**（`@ant-design/pro-components` 已在依赖中，ProLayout 可直接用）
> 状态：**未实现，契约先行。** 本文档定义结构，不代表功能已存在。

## 1. 与桌面工作区的分界

| 维度 | 桌面工作区 | 管理后台 |
|---|---|---|
| 路由 | `/canvas/*` 等 | `/admin/*`，**独立 Router 分支与 Layout** |
| 布局 | 全屏画布，无页面内边距 | ProLayout + 侧边导航 + 内容区 |
| 主题默认 | 暗色优先 | **明色优先** |
| 共享 | 共享色彩与字体令牌，**不共享布局组件** |

技术约束：不要在 `UserLayout` 里塞后台页面，也不要给画布套 ProLayout。两套布局各自独立，只共享 `app-theme.ts` 与设计令牌。

## 2. 外壳

```
┌──────┬────────────────────────────────────┐
│      │ 面包屑                     用户 ▾  │ 56px
│ 侧栏 ├────────────────────────────────────┤
│ 240  │                                    │
│      │  内容区 padding 24                 │
│      │  页面标题 20px/500                 │
│      │                                    │
└──────┴────────────────────────────────────┘
```

| 项 | 规定 |
|---|---|
| 侧栏宽 | 240px；< 1280px 折叠为 56px 图标栏 |
| 顶栏高 | 56px，含面包屑 + 全局搜索 + 用户菜单 |
| 内容区 | padding 24（窄屏 16），最大宽度不限制（表格需要横向空间） |
| 页面标题 | 20px / 500，下方一句说明（可选，13px `muted`） |
| 导航层级 | 最多两级；二级用可折叠分组，不用三级菜单 |
| 选中态 | 雾霭紫左条 2px + 浅紫底，不使用整块深色 |

### 导航项（建议）

概览 · 任务中心 · 模型管理 · 用户管理 · 额度与用量 · 运行日志 · 系统设置

**导航项不超过 8 个。** 超过说明信息架构没做完，不要靠折叠解决。

## 3. 四类页面模板

| 模板 | 用于 | 结构 |
|---|---|---|
| **列表页** | 任务、用户、日志 | 筛选条 + 表格 + 分页；操作列固定在右侧 |
| **详情页** | 单条记录 | 顶部摘要卡 + 分区信息 + 关联列表；或右侧 Drawer |
| **表单页** | 新建/编辑模型、用户 | 单列表单，宽 ≤ 640；分组用标题分隔，不用卡片嵌套 |
| **仪表盘** | 概览 | 4 个指标卡 + 1 个趋势图 + 1 个近期列表；不做大屏动效 |

规则：**表单永远单列**。两列表单在中文场景下会让标签与输入错位，阅读成本高于省下的滚动。

## 4. 表格规范

| 项 | 规定 |
|---|---|
| 行高 | 44（紧凑，默认）/ 56（舒适，含两行信息时） |
| 表头 | 12px / 500，`muted`，固定在顶部；列可排序时给排序图标 |
| 对齐 | 文本左对齐，数值右对齐（`tabular-nums`），状态居中 |
| 列宽 | 固定关键列，其余自适应；**不允许列宽随内容无限撑开** |
| 操作列 | 固定右侧，最多 3 个直接操作，其余进 `⋯` |
| 选中 | 支持批量时给复选框列；选中行用 `tableSelectedBg`（浅紫） |
| 批量操作 | 选中后出现浮条，说明"已选 N 项"+ 操作；`Esc` 取消选择 |
| 空态 | 区分"无数据"与"筛选无结果"，后者给"清除筛选" |
| 加载 | 首次加载骨架 3–5 行；翻页保留旧数据 + 局部 loading，不整表闪白 |
| 错误 | 表体区域显示错误 + 重试，不整页跳错误页 |

禁止：在表格里用彩色整行背景表达状态（用状态点 + 文字 + 必要时左侧 2px 条）。

## 5. 权限与危险操作

| 场景 | 规定 |
|---|---|
| 无权限 | 菜单不显示该入口（而不是显示后点进去报 403） |
| 只读 | 保留页面与数据，操作按钮隐藏或禁用并说明原因 |
| 危险操作 | 删除、重置、封禁：Modal 二次确认，**必须写出影响范围**（"该用户 N 个画布将无法访问"） |
| 批量危险操作 | 需要输入确认词或勾选"我了解影响" |
| 审计 | 所有管理操作在日志页可查：谁、何时、对谁、做了什么 |

文案要求：危险确认按钮写**动作名**（"删除 3 个用户"），不写"确定"。

## 6. 状态覆盖（每个页面必须齐）

| 状态 | 要求 |
|---|---|
| 空 | 一句说明 + 一个下一步动作 |
| 加载 | 骨架，不用居中 spinner |
| 错误 | 原因 + 重试 + 排查入口 |
| 无权限 | 说明 + 返回入口 |
| 部分失败 | 行级标记，不整表失败 |

## 7. 用户管理（专项）

| 项 | 规定 |
|---|---|
| 列表列 | 用户（头像+名+ID）、角色、状态、最近活跃、操作 |
| 角色 | 用标签展示（管理员 / 成员 / 只读），标签为中性底 + 文字，不用高饱和色块 |
| 状态 | 正常 / 已禁用 / 待激活，状态点 + 文字 |
| 详情 | Drawer：基本信息、所属画布数、任务数、最近操作 |
| 危险操作 | 禁用、删除、重置凭据，均需说明影响 |

---

## 8. Do / Don't

**Do**

- 后台明色优先，留出足够行高与列间距。
- 表格数值右对齐、状态点+文字。
- 危险操作写清影响范围。

**Don't**

- ❌ 把画布布局塞进后台，或给画布套 ProLayout。
- ❌ 两列表单、卡片套卡片。
- ❌ 侧栏放超过 8 个一级项。
- ❌ 无权限时先显示入口再报错。
- ❌ 批量操作不显示"已选数量"。
