# components/task-center.md · 任务中心

> 覆盖：画布底部任务条、任务列表、任务详情、状态机、失败与重试
> 代码：`components/canvas/canvas-task-bar.tsx`（雏形）、`services/api/doubao-bridge.ts`
> 状态：**画布任务条已实现；独立任务中心页面未实现，本文档为契约先行。**

---

## 1. 两级形态

| 形态 | 位置 | 职责 | 状态 |
|---|---|---|---|
| **任务条** | 画布底部，可折叠 | 让用户知道"现在有几个在跑、刚才是成功还是失败" | 已实现 |
| **任务中心** | 独立页面（后台侧） | 查历史、看详情、批量重试、排查原因 | 未实现 |

两者的**状态语义完全一致**，只有信息密度不同。不允许出现"任务条说成功、详情页说失败"的分裂。

---

## 2. 状态机

| 状态 | 语义 | 颜色 | 可执行动作 |
|---|---|---|---|
| `queued` | 已提交，等待执行 | `slate`（中性） | 取消 |
| `running` | 执行中 | `warning #f59e0b` | 取消、查看日志 |
| `succeeded` | 完成并有产物 | `success #22c55e` | 查看、下载、重新生成 |
| `failed` | 失败 | `danger #ef4444` | 重试、查看原因 |
| `cancelled` | 用户取消 | 中性 | 重新生成 |

约束：

- 状态**只由后端/桥接返回决定**，前端不自行推断（例如不因为超时就本地改成 failed）。
- 终态（succeeded / failed / cancelled）不可再变。
- 失败原因必须保留站点或服务的**原文**，附加一句人话解释。

## 3. 任务条（画布内）

```
─────────────────────────────────────────
▲ 任务  ● 生成中 2  ·  ✓ 完成 5  ·  ✕ 失败 1
   画布 3 · 视频节点 1 · 03:12
```

| 项 | 规定 |
|---|---|
| 高度 | 折叠 36px，展开 ≤ 180px（超过则内部滚动） |
| 位置 | 画布底部通栏，浮在画布上，不推挤画布尺寸 |
| 背景 | `theme.toolbar.panel`（半透明面板色）+ 上边框 1px |
| 计数 | 运行中 / 完成 / 失败三个计数，用状态色小圆点，不用色块 |
| 列表行 | 32px：状态点 + 任务名（截断）+ 模型 + 耗时 + `⋯` |
| 排序 | **运行中置顶**，其余按时间倒序 |
| 空态 | 不显示整个任务条（没有任务时不要留一条空条） |
| 桥接未运行 | 条内一行中性提示"桥接未运行"+ 启动入口，不用红色 |
| 轮询 | 定时刷新不闪烁、不改变展开状态、不重置滚动位置 |

任务条**不承担详情职责**：点击行打开对应节点或详情抽屉，不在条内展开长日志。

## 4. 任务中心（契约先行，未实现）

### 页面结构

```
┌ 筛选：状态 · 来源 · 模型 · 时间范围 ─────────┐
├ 表格 ──────────────────────────────────────┤
│ 状态  任务      模型      耗时   时间   操作 │
│ ● 运行  生成图片  Seedream  12s   10:20  ⋯  │
│ ✓ 完成  生成视频  Seedance  1m4s  10:18  ⋯  │
└────────────────────────────────────────────┘
```

| 项 | 规定 |
|---|---|
| 布局 | 后台轨：页面边距 24，表格行高 44（紧凑）/ 56（舒适） |
| 状态列 | 状态点 + 文字（不只靠颜色传达） |
| 任务列 | 任务名 + 来源节点/画布（次要行） |
| 操作 | 查看详情、重试、取消、下载产物 |
| 详情 | 右侧 Drawer（宽 480–560），含参数快照、日志、产物 |
| 筛选 | 状态多选 + 时间范围，筛选条件写进 URL |
| 空态 | 分两种：从未有过任务（引导去画布）/ 筛选无结果（给"清除筛选"） |
| 分页 | 默认 20 条，服务端分页；不做无限滚动（难以定位） |

### 详情抽屉内容顺序

1. 状态 + 任务名 + 时间
2. 失败原因（如有，置顶，原文 + 解释）
3. 参数快照（模型、比例、时长、提示词）
4. 产物（缩略图 / 播放器 / 下载）
5. 运行日志（mono，默认折叠，可复制）

## 5. Do / Don't

**Do**

- 状态用"点 + 文字"，不只用颜色（色盲可用性）。
- 运行中永远置顶。
- 失败给原文 + 人话 + 重试三件套。

**Don't**

- ❌ 前端自行把超时改成失败。
- ❌ 无任务时保留空任务条。
- ❌ 任务条里展开长日志。
- ❌ 用 toast 通知单个任务完成（会打断创作流）。
- ❌ 任务中心用无限滚动。
