# components/primitives.md · 基础件

> 覆盖：按钮、输入、下拉、弹层、提示、标签、空态、加载、滚动条、图标
> 代码：`web/src/components/ui/*`、`web/src/lib/app-theme.ts`、`web/src/styles/globals.css`
> 依赖：Ant Design 6（主）、Radix（局部）、lucide-react（图标）

---

## 1. 按钮

| 类型 | 用在哪 | 规则 |
|---|---|---|
| primary | 一屏唯一主操作（生成、保存、连接） | 雾霭紫填充，无阴影（`primaryShadow: none`），字重 500 |
| default | 次要操作 | 描边按钮，不用灰底 |
| text | 画布内、工具栏、表格行内 | 透明底，hover 才给 `black/5` / `white/10` |
| danger | 删除、清空 | 红色文字或红底（仅确认弹窗里用红底） |
| link | 正文内跳转 | 中性色，hover 转雾霭紫（现有 `colorLink` 配置） |

规则：

- **一屏一个 primary。** 出现两个即为设计错误。
- 高度：画布 28 / 32；后台 32。
- 图标 + 文字时，图标 14px，间距 6px。
- **破坏性操作必须有文字**，不允许只有图标（"垃圾桶"图标在密集界面里极易误点）。
- loading 时按钮宽度不变（避免布局跳动），禁用重复点击。
- 禁止给按钮加渐变、发光、立体投影。

## 2. 输入

| 项 | 规定 |
|---|---|
| 高度 | 画布 28 / 后台 32 |
| 圆角 | 8 |
| 描边 | 默认 `--input`（`#e4dfee` / `rgba(255,255,255,.12)`） |
| 聚焦 | 1px 雾霭紫描边（`--ring`），**不加外发光** |
| 错误 | 1px `#ef4444` + 下方 11–12px 红字说明 |
| 禁用 | 底色降一档，文字 `faint`，不使用 `opacity: .5`（会连带文字一起糊） |
| 占位符 | `theme.node.placeholder` / `--muted-foreground`，不写"请输入…"这类废话 |

文本域默认禁止手动拉伸（`resize: none`，已在全局设置）；需要自动增高的用 `rows` + 内容高度。

## 3. 下拉 / 选择

- 弹层背景统一 `colorBgElevated`（`#ffffff` / `#12101c`），由 `app-theme.ts` 的 `Dropdown` / `Select` / `Menu` 组件 Token 控制。
- hover 底 `controlItemBgHover`，选中底 `controlItemBgActive`，选中文字保持 `itemText`（**不用品牌色文字**，避免扫读疲劳）。
- 选项高度 32px；多选标签用 8px 圆角 chip，不用胶囊。
- 长列表超过 12 项时必须支持搜索。
- **禁止在业务组件里单独覆盖弹层颜色**——一律改 `app-theme.ts`。

## 4. 弹层三级

| 级 | 组件 | 用于 | 尺寸 | 动效 |
|---|---|---|---|---|
| L1 | Tooltip / Popover | 轻量说明、1–4 个参数 | 自适应，≤ 360 | 160ms / 位移 4–6px |
| L2 | Drawer | 复杂表单、详情、日志 | 480–560（右侧） | 240ms / 位移 24px |
| L3 | Modal | 必须阻断的确认、二维码登录 | 400–560 | 200ms / 位移 8px |

规则：

- **长表单禁止用 Modal**，用 Drawer。
- 确认弹窗必须写清"做什么 + 影响什么"，按钮写动作名。
- 一个弹层内不再叠第二个 Modal（需要时改成分步或 Drawer 内分步）。
- 所有浮层加 `data-canvas-no-zoom`，避免画布缩放吞掉浮层交互。
- 关闭统一支持 `Esc`；点击外部关闭用 `pointerdown` capture。

## 5. 提示（Toast / Message）

| 场景 | 用什么 |
|---|---|
| 操作成功但无需用户确认（复制、保存） | 轻提示，2s 自动消失 |
| 操作失败 | **不用 toast**，就地显示原因 |
| 后台长任务的阶段变化 | 任务条 / 状态列，不用 toast |
| 需要用户决策 | Modal，不用 toast |

原则：**toast 只用于"和用户当前注意力无关但需要知道"的事**。生成完成、保存成功这类，就地反馈更好。

## 6. 标签 / 状态

| 类型 | 视觉 |
|---|---|
| 中性标签 | `--secondary` 底 + `--secondary-foreground` 字，8px 圆角 |
| 状态点 | 6px 圆点 + 8px 间距 + 文字（**不只靠颜色**） |
| 能力标签 | 11px，中性底，用于模型能力、站点来源 |
| 计数徽标 | 16px 高，最小宽 16，胶囊 |

禁止：用高饱和实心色块做标签底（除危险确认按钮）。

## 7. 空态

四要素，缺一不可：

1. **一句人话说明**（这里会有什么）
2. **一个图标或极简构成**（用 lucide，不用插画角色）
3. **一个下一步动作**（按钮或链接）
4. **不要**大段说明文字

区分三种空态：

| 类型 | 文案方向 |
|---|---|
| 从未有过 | "还没有画布，创建一个开始" |
| 筛选无结果 | "没有符合条件的记录" + 清除筛选 |
| 无权限 | "你没有访问权限" + 申请/返回 |

---

## 8. 加载

| 时长 | 表现 |
|---|---|
| < 300ms | 不显示任何加载态 |
| 300ms–2s | 骨架屏（列表/卡片/表格行） |
| > 2s | 骨架 + 阶段文案；提供取消 |

禁止：居中转圈占满整页、加载态 + 空态同时出现、进度条造假。

## 9. 滚动条

项目已有两套工具类，直接复用，不新增：

| 类 | 行为 | 用在哪 |
|---|---|---|
| `.thin-scrollbar` | 4px 细条，常显 | 面板、日志、代码块 |
| `.hover-scrollbar` | 默认隐藏，hover 才显 | 画布侧栏、素材网格 |
| `.hide-scrollbar` | 隐藏 | 横向 tab 条、跑马灯 |

## 10. 图标

- 统一 `lucide-react`，尺寸 14（行内）/ 16（按钮）/ 20（空态）。
- 描边宽度用默认，不改 `strokeWidth`（改了会与其他图标不一致）。
- 图标颜色继承文字色；语义色图标（成功/警告/危险）显式设色。
- 同一屏内不混用 Ant Design Icons 与 lucide（`@ant-design/icons` 只允许出现在 antd 组件内部默认图标）。

---

## 11. Do / Don't

**Do**

- 用 `app-theme.ts` 统一改弹层颜色，而不是在业务组件里逐个覆盖。
- 状态永远"点 + 文字"。
- 空态给动作，加载给骨架。

**Don't**

- ❌ 一屏两个 primary。
- ❌ 用 toast 报告失败。
- ❌ 给输入框加聚焦发光。
- ❌ 用 `opacity` 表达禁用。
- ❌ Modal 里塞长表单。
- ❌ 新增第三套滚动条样式。
