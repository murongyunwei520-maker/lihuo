# components/model-management.md · 模型管理

> 覆盖：模型选择弹窗、渠道配置、模型能力标签、模型脚本编辑、内置站点模型
> 代码：`components/layout/model-select-modal.tsx`、`model-script-editor.tsx`、`channel-editor-drawer.tsx`、`app-config-modal.tsx`、`model-picker.tsx`、`constants/doubao-builtin.ts`
> Schema：`stores/model-schema.ts`（`ModelDefinition` / `ModelSupportedFeatures`）

---

## 1. 两个场景，两种密度

| 场景 | 入口 | 用户目标 | 密度 |
|---|---|---|---|
| **选模型** | 画布节点、composer 下拉 | 30 秒内选对 | 极高，行内不解释 |
| **配模型** | 配置页 / 渠道抽屉 | 把模型接上并确认可用 | 中等，需要说明与校验 |

两者共用同一份模型数据，但**不共用同一个列表组件**：选择器是"命令面板"，配置页是"表单"。硬用一个组件会两边都别扭。

## 2. 模型选择器（命令面板）

```
搜索模型…
─────────────────────────
豆包 · 内置
  Seedream 5.0 Pro   图片 · 2K
  Seedance 2.5       视频 · 4–15s
OpenAI 兼容
  gpt-image-1        图片
本地
  llama-3.1-8b       文本
```

| 项 | 规定 |
|---|---|
| 宽度 | 320–400px，不超过 400 |
| 行高 | 36px；两行信息时 48px |
| 分组 | 按 provider 分组，组标题 11px，`faint` |
| 搜索 | 打开即聚焦；支持模型名、provider 名模糊匹配 |
| 键盘 | `↑↓` 移动、`Enter` 选中、`Esc` 关闭；必须有高亮当前项 |
| 能力标签 | 行尾小标签：`图片` / `视频` / `文本` / `音频`，11px，中性底 |
| 禁用项 | 出现在列表但置灰，**行尾必须说明原因**（"未配置 Key"/"站点不匹配"） |
| 空结果 | "没有匹配的模型" + "去配置"入口 |

**禁止**：只显示可用模型而隐藏不可用的。用户需要知道"我有这个模型，只是没配好"，这比"它不存在"更有用。

## 3. 能力标签

标签只有一组，不允许各页面自创：

| 能力 | 来源字段 | 展示 | 用途 |
|---|---|---|---|
| 参考图 | `referenceImage` | `参考图` | 决定节点是否显示参考图条 |
| 参考视频 | `referenceVideo` | `参考视频` | 视频节点模式 |
| 音频生成 | `generateAudio` | `音频` | 参数面板开关 |
| 水印 | `watermark` | `水印` | 参数面板开关 |
| 自定义比例 | `customRatio` | `自定义比例` | 显示自定义宽高 |
| 自定义时长 | `customDuration` | `自定义时长` | 显示时长滑块 |

**能力标签驱动界面，不是装饰。** 标签为真 → 对应控件出现；为假 → 控件不渲染。若某能力拿不到（未知），按"不支持"处理并在配置页提示"能力未知，可能缺少字段"。

## 4. 渠道与配置

| 项 | 规定 |
|---|---|
| 结构 | 左侧渠道列表（按 provider），右侧表单 |
| 必填标记 | `*` 前缀 + 表单底部汇总错误，字段级红字 |
| 密钥 | 默认掩码显示，提供"显示"按钮；保存后不再回显明文 |
| 测试连接 | 一个 secondary 按钮，结果显示在字段下方而非 toast |
| 危险操作 | 删除渠道 → 二次确认，说明"该渠道下 N 个模型将不可用" |
| 保存 | 底部固定操作条：取消 / 保存；保存中按钮 loading 且禁用重复点击 |

敏感信息规则：**API Key 存浏览器本地**（当前实现），因此界面上必须有一句明确说明，不允许暗示"已加密上传云端"。

## 5. 模型脚本编辑

- 编辑器为 CodeMirror（已用 `@uiw/react-codemirror`），mono 12–13px。
- 编辑器容器圆角 8，描边 1px；聚焦时描边转雾霭紫，不加发光。
- 错误提示在编辑器下方，给出行号。
- 提供"格式化"与"重置为默认"两个次要动作。
- 脚本变更后必须能"试运行"（发送一个最小请求），否则用户只能靠猜。

## 6. 内置站点模型（豆包 / Dola）

| 项 | 规定 |
|---|---|
| 命名 | 与站点面板文案一致，带 `（豆包）` / `（Dola）` 后缀 |
| 站点标签色 | 豆包=雾霭紫，Dola=冰川蓝（只标识来源，不表达状态） |
| 站点不匹配 | 选择 Dola 模型后，账号下拉只列 Dola 账号；错配不显示为可选项 |
| 能力范围 | 比例/时长以真实账号态 `video-caps.json` 为准（当前含「自动」，4–15s） |
| 文案变更 | 站点改文案后不猜，直接展示站点真实选项（日志里打印真实列表） |

**不允许在界面写死比真实能力更大的范围**。用户选了必然失败的选项，比少一个选项更糟。

---

## 7. Do / Don't

**Do**

- 选择器里显示所有模型，用置灰 + 原因区分"不可用"。
- 能力标签直接决定控件出现与否。
- 配置页把"测试连接"放在表单内，结果就地显示。

**Don't**

- ❌ 把选择器和配置表单做成同一个组件。
- ❌ 用图标代替能力文字标签（用户不知道那个小图标是什么意思）。
- ❌ 保存后回显完整 API Key。
- ❌ 删除渠道只弹"确定删除吗"，不说明影响面。
- ❌ 硬编码模型能力范围绕过 Schema。
