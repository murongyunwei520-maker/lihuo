# components/canvas-surface.md · 无限画布

> 覆盖：画布容器、背景网格、选区、缩放、顶部工具栏、侧边面板、小地图、右键菜单
> 代码：`components/canvas/infinite-canvas.tsx`、`canvas-toolbar.tsx`、`canvas-top-bar.tsx`、`canvas-side-panel.tsx`、`canvas-side-dock.tsx`、`canvas-mini-map.tsx`、`canvas-zoom-controls.tsx`、`canvas-selection-toolbar.tsx`、`canvas-context-menu.tsx`
> 主题：`lib/canvas-theme.ts` 的 `canvasThemes`

---

## 1. 结构分层

从下到上五层，职责严格分离：

| 层 | 内容 | 规则 |
|---|---|---|
| L0 底 | 画布背景（点 / 线 / 空白） | 唯一允许铺满视口的层 |
| L1 连接 | 节点间连线 | 只画关系，不承载交互按钮 |
| L2 节点 | 所有 `CanvasNode` | 见 `node.md` |
| L3 覆盖 | 框选、临时工具条、上下文菜单 | 随交互出现，交互结束即销毁 |
| L4 框架 | 顶部工具栏、侧边面板、缩放控件、小地图、底部任务栏 | 固定于视口，不随画布平移 |

层序只用语义顺序管理。新增层必须在既有区间内取值，**不引入负数或 1000 以上的 z-index**。

## 2. 背景（三种模式）

| 模式 | 用途 | 亮色 | 暗色 |
|---|---|---|---|
| `dots` | 默认，适合自由创作 | 底 `#f4f2f9` + 点 `rgba(80,66,110,.20)` | 底 `#0a0810` + 点 `rgba(190,170,220,.18)` |
| `lines` | 对齐要求高的排版式布局 | 线 `rgba(80,66,110,.09)` | 线 `rgba(190,170,220,.07)` |
| `blank` | 图片、视频审阅时 | 纯底 | 纯底 |

规则：

- 网格透明度**只做背景暗示，不参与构图**。用户能看见点，但不会注意到点。
- 网格随缩放同步缩放，缩放极小时（约 < 40%）允许淡出，避免出现摩尔纹。
- 背景切换是**用户设置**，不随内容自动改变。

## 3. 选区

| 项 | 规定 |
|---|---|
| 颜色 | `theme.canvas.selectionStroke`（`#6b57a8` / `#b9ace8`），填充 `selectionFill` |
| 描边宽度 | 1px，按缩放反向补偿（缩放后视觉宽度恒定） |
| 框选矩形 | 1px 虚线或半透明填充，松手即消失，**不做收缩动画** |
| 多选 | 每个节点各自描边，不画外包围框（除非是分组） |
| 关联高亮 | 与选中节点有连线关系的节点用 `theme.node.muted` 描边，弱于主选中 |

**选中只用一个颜色：雾霭紫。** 不得为不同来源（点击选中 / 框选 / 关联）引入不同颜色，关联态用**强度**区分而非色相。

> 已收敛：`canvas-node.tsx` 的节点选中曾用硬编码 `selectionBlue = "#2f80ff"`，现统一读 `theme.canvas.selectionStroke`；节点间"可引用 / 已引用"关系改用 `theme.canvas.relationStroke`（冰川蓝）。

## 4. 顶部工具栏（画布框架）

AGENTS.md 已定风格，此处固化为可执行条款：

| 项 | 规定 |
|---|---|
| 视觉 | 无边框、无阴影、无胶囊底，直接融入画布背景 |
| 按钮 | 透明底 + 图标（14–16px），文字可选 |
| hover | `bg-black/5`（亮）/ `bg-white/10`（暗），100ms |
| 选中/激活 | 允许用 `theme.toolbar.activeBg`，**仅表达状态**，不作装饰底 |
| 高度 | 32px 控件，整条工具栏垂直内边距 8px |
| 分组 | 组间用 8px 空隙或 1px 竖线分隔，不用分割块 |
| 文字 | 12px，`theme.toolbar.item` |

禁止：给工具栏加白色卡片底、加圆角容器包住整条工具栏、给每个按钮加边框。

## 5. 侧边面板 / 资源面板

| 项 | 规定 |
|---|---|
| 宽度 | 固定档位（以代码为准），展开/收起用宽度过渡 180ms |
| 面板底 | `theme.node.panel`（`#ffffff` / `#100d1a`） |
| 内边距 | 12px |
| 分组 | 12px 间距 + 1px 分隔线，**不给每组加卡片底** |
| 列表项 | 32px 高，hover `theme.toolbar.itemHover`，选中 `activeBg` |
| 缩略图 | 图片类显示缩略图；文本/配置/视频/音频等**不给灰色背景**，图标直接展示 |

这条"非图片类型不给底色"是画布干净的关键：一旦每个列表项都有灰底，面板立刻变成色块拼贴。

---

## 6. 缩放控件与小地图

- 缩放控件：竖向或横向 3–4 个图标按钮（放大、缩小、适应视图、100%），样式同工具栏按钮。
- 缩放范围与步进**以代码为准**，规范不另立数值。
- 小地图：默认半透明，hover 提高不透明度；尺寸不超过视口的 1/6；不显示节点文字。
- 小地图在窄视口（< 1280px）自动隐藏，不折叠成按钮。

---

## 7. 右键菜单

| 项 | 规定 |
|---|---|
| 触发 | `contextmenu`，画布空白处与节点上各一套菜单 |
| 位置 | 指针右下 8px，超出视口自动翻转 |
| 出现 | 120ms 淡入，无位移动画 |
| 项高 | 32px，图标 14px + 文字 12px |
| 危险项 | 红色 `#ef4444`，**必须带文字**，不与普通项混排在同一组 |
| 关闭 | 点击外部（`pointerdown` capture）、`Esc`、滚动、缩放 |

---

## 8. 交互契约

| 操作 | 行为 |
|---|---|
| 滚轮 | 以指针为中心缩放 |
| 空格 + 拖拽 | 平移 |
| 拖拽空白 | 框选 |
| `Shift` + 点击 | 加选 / 减选 |
| `Ctrl/Cmd + Z` | 撤销 |
| 双击空白 | 打开创建菜单 |
| `Esc` | 关闭浮层 → 取消选中（逐级退出） |

**高频交互不得触发全局重渲染**：平移/缩放过程中的坐标与系数留在本地 ref 或 state，松手后才落库。

## 9. Do / Don't

**Do**

- 让画布背景明显比节点表面深一档，节点自然"浮"起来，不加阴影。
- 面板分组靠间距与分隔线，靠的不是底色。
- 所有覆盖层在交互结束后立即销毁。

**Don't**

- ❌ 给工具栏/面板加白卡片 + 阴影 + 圆角"三件套"。
- ❌ 用灰色填充表达按钮默认态。
- ❌ 在画布上叠页面级 loading 遮罩。
- ❌ 为不同选中来源用不同颜色。
- ❌ 小地图显示节点标题文字。
