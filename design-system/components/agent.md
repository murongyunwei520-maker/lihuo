## 1. 定位：它是执行器，不是聊天机器人

| 聊天产品 | 离火 Agent |
|---|---|
| 追求对话流畅 | 追求任务可验证 |
| 消息是主体 | **动作与结果是主体**，文字是说明 |
| 允许长段自然语言 | 优先结构化：做了什么、改了什么、结果如何 |
| 失败就道歉 | 失败给原因 + 可执行的下一步 |

这条定位决定了下面所有视觉选择：**信息密度高于留白，状态显式高于氛围。**

## 2. 结构

```
┌─ Agent 面板 ──────────────────────────┐
│ [对话] [历史] [日志] [技能]            │  ← tabs，32px
├───────────────────────────────────────┤
│ 用户：把画布导出成 2 倍图              │
│                                       │
│ ▸ 调用工具 export_canvas ×1  (折叠)    │  ← 工具调用默认折叠
│ ▼ 结果                                │
│   已导出 3 个节点                       │
│   ```json { ... } ```                 │  ← mono 代码块
│                                       │
├───────────────────────────────────────┤
│ [ @引用画布节点 ]                      │
│ ┌───────────────────────────────────┐ │
│ │ 描述你的需求…                      │ │
│ └───────────────────────────────────┘ │
│ [模型 ▾]                    [ 发送 ]  │
└───────────────────────────────────────┘
```

| 项 | 规定 |
|---|---|
| 面板宽度 | 窄（默认）与宽两档，宽度过渡 180ms，不遮挡画布中心 |
| Tab 高 | 32px，选中用 1px 下划线（雾霭紫），不做胶囊底 |
| 消息间距 | 同角色 8px，换角色 16px |
| 消息正文 | 13px / 1.6；不使用气泡尾巴、不区分左右对齐（统一左对齐，靠头像与角色标签区分） |
| 代码块 | mono 12px，底色比面板深/浅一档（`theme.node.fill` 量级），右上角复制按钮 |
| 工具调用 | 默认折叠为一行："工具名 × 次数"，展开看入参与返回 |
| 时间戳 | 11px，`theme.node.faint`，只在时间跨度 > 5 分钟时显示 |

**不做气泡左右分栏**：Agent 的消息常含代码、表格、长列表，气泡会把可用宽度吃掉。统一左对齐 + 角色标签是更高效的排版。

## 3. 消息状态

| 状态 | 表现 |
|---|---|
| 流式输出中 | 末尾光标；底部"回到最新"按钮在用户上滚时出现 |
| 完成 | 输入框恢复可用，发送按钮回 primary |
| 工具调用中 | 该行前方 12px 旋转或脉冲指示；**不等于**整块 loading |
| 等待用户确认 | 该条消息给 1px 雾霭紫描边 + 明确的"确认/取消"两个按钮 |
| 失败 | 红色左边框（1px）+ 原因 + 重试 |
| 被中断 | 灰色标签"已中断"，保留已产出的内容 |

**并发约束**：消息必须同时按 `threadId`、`turnId`、`itemId` 归属。视觉上表现为——切换 thread 时列表整体替换，不允许新旧 thread 的消息混排（这是历史数据一致性问题在界面的直接体现）。

## 4. 输入区

- 单行起步，随内容增高，最多 6 行后内部滚动。
- `Enter` 发送，`Shift + Enter` 换行；输入法组合中不发送。
- 支持 `@` 引用画布节点：插入 chip（冰川蓝），悬停显示节点缩略预览。
- 运行中允许继续输入，但发送按钮变为"排队"或禁用，取决于是否支持并发——**不显示可点但无反应的按钮**。
- 附件/截图入口放左侧，图标 14px。

## 5. 连接态（`agent-connect-view`）

未连接是首次使用的必经状态，不能做成错误页。

| 状态 | 文案方向 | 视觉 |
|---|---|---|
| 未配置 | 说明需要什么、给出配置入口 | 中性 + 一个 primary 按钮 |
| 连接中 | "正在连接本地 Agent…" | 脉冲指示，≤ 10s |
| 连接失败 | 具体原因（端口占用 / 未启动 / 版本不匹配） | 红色左边框 + 重试 + 排查链接 |
| 已连接 | 不在主区显示，仅在标题栏给一个小绿点 | 极弱 |

## 6. 历史 / 日志 / 技能

| Tab | 内容 | 关键规则 |
|---|---|---|
| 历史 | 按 thread 分组的会话列表 | 32px 行高，单行标题截断，hover 显示删除 |
| 日志 | 原始事件流（mono 11–12px） | 可复制、可下载；默认折叠长 JSON |
| 技能 | 可用 Skill 列表 | 每项显示名称 + 一句用途 + 启用开关 |

日志是排障界面，允许高密度，但**必须可复制**——不允许只能看不能拿。

---

## 7. Do / Don't

**Do**

- 工具调用默认折叠，让"结果"成为视觉主体。
- 用左边框表达失败与等待确认，不用整块变色。
- 流式输出时保持滚动跟随，但用户上滚后立即停止跟随并给出"回到最新"。

**Don't**

- ❌ 做聊天气泡（左右分栏、尾巴、圆角卡片）。
- ❌ 把整块消息做成 loading 态。
- ❌ 用 emoji 或语气词当状态（"正在努力思考中~"）。
- ❌ 日志区不可选中、不可复制。
- ❌ 混排不同 thread 的消息。
