# components/params-panel.md · 模型参数面板

> 覆盖：Schema 驱动的参数表单、分组、条件显示、滑块、模型选择
> 代码：`components/DynamicParamsPanel.tsx`、`image-settings-panel.tsx`、`video-settings-panel.tsx`、`audio-settings-panel.tsx`、`text-settings-panel.tsx`、`canvas-*-settings-popover.tsx`、`model-picker.tsx`
> Schema：`stores/model-schema.ts` 的 `ParameterSchema`

---

## 1. 唯一数据来源

参数面板**不自己存状态**。参数值归属两处之一：

| 归属 | 用哪个字段 | 场景 |
|---|---|---|
| 全局 AI 配置 | `ParameterSchema.configKey` → `AiConfig` | 用户级默认值（模型、比例、质量） |
| 节点级覆盖 | `params` 对象 | 单个节点的临时调整 |

禁止新增第三处参数存储。新增参数时，在 `ParameterSchema` 里声明 `configKey` 或 `apiField`，不要在组件里 `useState` 一份平行状态。

---

## 2. 参数类型与控件映射

| `type` | 控件 | 何时用 |
|---|---|---|
| `select` | 下拉（Ant Design `Select`） | 选项 ≤ 8 且互斥（模型、比例、质量） |
| `slider` | 滑杆 + 数值输入 | 连续区间（时长、强度、数量） |
| `number` | 数字输入 | 精确值、步长明确 |
| `boolean` | 开关 | 二值（生成音频、去水印） |
| `text` | 单行输入 | 短文本、种子 |
| `textarea` | 多行输入 | 提示词补充、负向提示词 |
| `group` | 折叠分组容器 | 仅作组织，不承载值 |

**`select` 的选项必须来自模型能力，不能硬编码。** 例如视频比例与时长以豆包账号态 `.doubao-accounts/<id>/state/video-caps.json` 为准（当前比例含「自动」，时长 4–15s）。给用户超出真实范围的选项，等于制造必然失败的请求。

---

## 3. 结构

```
┌─ 面板 ───────────────────────┐
│ 模型        [ Seedance 2.5 ▾ ]│  ← 必填，永远第一
│ 比例        [ 16:9         ▾ ]│
│ 时长        [────●────] 10 秒 │
│ 数量        [────●────]  2    │
│                              │
│ ▸ 高级设置                    │  ← 默认折叠
└──────────────────────────────┘
```

| 项 | 规定 |
|---|---|
| 行高 | 32px（控件），行间距 8px |
| 标签 | 左对齐，固定宽度使控件起点对齐；12px，`theme.node.muted` |
| 控件 | 右对齐撑满剩余宽度，28–32px 高 |
| 分组间距 | 12px + 1px 分隔线，**不给分组加卡片底** |
| 折叠组 | 默认折叠，标题 12px，箭头 12px |
| 一屏限制 | 同时展开的组不超过 3 个；超出的必进折叠 |

---

## 4. 分组顺序（固定）

1. **模型**（必填，永远第一行）
2. **尺寸类**（比例 / 分辨率 / 尺寸）
3. **生成类**（时长 / 数量 / 质量 / 种子）
4. **高级**（水印、音频、负向提示词、自定义参数）

顺序一旦打乱，用户每次都要重新找。新增参数只能插入到对应组的末尾。

---

## 5. 条件显示（`showIf`）

```ts
showIf: { dependsOn: "ratio", equals: "custom" }
showIf: { dependsOn: "model", in: ["seedance-2.5", "seedance-1.0"] }
```

规则：

- 条件满足即显示，**不满足时直接隐藏，不显示为禁用**。禁用项会让面板变长且制造困惑。
- 联动是即时的：改上游参数后，下游参数在同一帧出现/消失，不做高度展开动画（避免面板跳动）。
- 联动不得清空用户已选值，除非该值在新情况下无意义（例如比例从"自动"改为具体值后，自定义宽高才生效）。
- 不允许出现"删掉上游参数后下游参数仍显示"的悬空状态。

---

## 6. 滑块规范

- 滑块与数值输入**成对出现**：拖动看趋势，输入要精确。
- 数值显示带单位（`10 秒`、`2 张`），单位字号降一级、颜色 `theme.node.faint`。
- 步长必须来自 Schema 的 `step`，不取默认 1。
- 拖动时不触发请求，松手（`onChangeComplete`）才落库，避免高频写入。
- 数值使用 `tabular-nums`，避免拖动时数字左右跳动。

---

## 7. 状态

| 状态 | 表现 |
|---|---|
| 默认 | 显示当前值或占位 |
| 未选模型 | 整个面板替换为"先选择模型"引导 + 选择入口，不显示灰色空表单 |
| 模型无此能力 | 该参数整行不渲染（依赖 `ModelSupportedFeatures`） |
| 加载模型列表 | 模型下拉显示骨架，其他参数保持可用 |
| 保存失败 | 就地提示，保留用户输入 |

---

## 8. Do / Don't

**Do**

- 让最常改的三个参数（模型、比例、时长）在第一屏无折叠可见。
- 标签对齐、控件对齐，整块像一个表格。
- 参数摘要同步回节点元信息行，用户不用打开面板也知道当前设置。

**Don't**

- ❌ 把 20 个参数平铺展开。
- ❌ 用开关表达三态（应该用 `select`）。
- ❌ 给每个参数加说明文字（说明放 tooltip，`description` 字段）。
- ❌ 在面板里放"应用/确定"按钮——参数应立即生效。
- ❌ 硬编码选项范围，绕过 Schema。
