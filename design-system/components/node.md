# components/node.md · 模型节点

> 覆盖：节点卡片、状态、内容区、缩放、hover 工具条、连线锚点、节点内参数
> 代码：`components/canvas/canvas-node.tsx`、`canvas-node-hover-toolbar.tsx`、`canvas-node-prompt-panel.tsx`、`nodes/builtin-nodes.tsx`、`nodes/lihuo/*`
> 主题：`canvasThemes.node`

---

## 1. 节点类型与默认尺寸

| 类型 | 默认尺寸 | 说明 |
|---|---|---|
| `image` | 以内容比例为准 | 尊重原图宽高比，不自由拉伸 |
| `video` | 16:9 起 | 首帧必须立即出图，不留黑块 |
| `text` | 340 × 240（回退规格） | 可调字号 |
| `audio` | 回退规格 | 波形 + 播放控制 |
| `config` | 回退规格 | 模型/参数聚合节点 |
| `group` | 由子节点包围盒决定 | 拖入即成为成员 |
| `lihuo:note` | 280 × 200 | 便签 |
| `lihuo:prompt-lab` | 340 × 220 | 提示词实验台 |
| `lihuo:director` | 760 × 520 | 导演台（大画布面板） |

回退规格统一 340 × 240。新增节点类型必须在 `LIHUO_NODE_DEFINITIONS` 或 `builtin-nodes.tsx` 注册 `defaultSize`，不允许"创建后再让用户手动调大小"。

## 2. 结构解剖

```
┌─────────────────────────────────────┐
│ [icon] 标题                    [状态]│  ← 头部 32px
├─────────────────────────────────────┤
│                                     │
│            内容区                    │  ← 图片 / 视频 / 文本 / 波形
│                                     │
├─────────────────────────────────────┤
│ 参数摘要 · 模型名 · 尺寸 · 体积        │  ← 元信息 24px，10–11px 字
└─────────────────────────────────────┘
        ↑ hover 时上方浮出工具条
```

| 区域 | 规定 |
|---|---|
| 头部高度 | 32px（标题 13px/500，图标 14px） |
| 元信息行 | 24px，11px，`theme.node.faint` |
| 内边距 | 内容区 0（图片贴边），文本类 12px |
| 圆角 | 12px（与面板一致），内容区继承并在内侧裁切 |
| 描边 | 1px，`theme.node.stroke`；选中 `theme.canvas.selectionStroke` |
| 表面 | `theme.node.panel`（`#ffffff` / `#100d1a`），**不加阴影**（e0 平面） |

## 3. 状态

| 状态 | 视觉 | 交互 |
|---|---|---|
| idle | 常态描边 | 可拖拽、可连线 |
| loading | 描边呼吸（1400ms）+ 内容骨架 | 可取消，禁止重复提交 |
| success | 常态 + 结果落位（240ms 淡入） | 可下载、可重试、可放大查看 |
| error | 1px 红色描边 + 内容区错误文案 + 重试按钮 | 保留用户输入，可原地重试 |

补充状态（不改变外观骨架，只加弱标记）：

- **关联态**：与选中节点相连时描边转 `theme.node.muted`，弱于主选中。
- **连线目标态**：可落入时给 1px 高亮描边，不做磁吸弹跳。
- **引用选择态**（`target` / `disabled` / `available`）：用遮罩透明度表达，`available` 时描边高亮。
- **分组拖入态**：整块高亮 + 内侧半透明填充，表示"将成为成员"。

**禁止**：用不同颜色表达不同状态（loading 黄 / error 红 / success 绿同时出现在节点描边上）。节点描边只有两种语义：**选中**（紫）与**异常**（红）。

## 4. 尺寸与缩放

- 图片/视频节点：**必须尊重原始比例**。除非功能明确要求自由变形（如裁剪），否则不允许拉伸。
- 调整大小：四角手柄，热区 ≥ 12×12，视觉可更小。
- 最小尺寸以代码为准；规范只约束"最小尺寸必须保证标题与一个操作按钮可点"。
- 节点内文字**不随节点缩放而缩放**（缩放画布时用 CSS scale 统一缩放，不要重新计算字号）。

## 5. hover 工具条

浮动于节点上方居中，是画布内信息密度最高的控件。

| 项 | 规定（与现有实现一致） |
|---|---|
| 位置 | 节点顶部外侧，水平居中，向上偏移一个间距 |
| 高度 | 48px |
| 圆角 | 18px |
| 背景 | 白色（亮色场景）；暗色画布需随主题，见附录 A 第 7 条 |
| 描边 | 1px `black/10` |
| 阴影 | `0 8px 28px rgba(15,23,42,.12)`（唯一允许 e1 的地方） |
| 按钮 | 内部 36px 高、`rounded-lg`，hover `#f0f0f1` |
| 字号 | 15px（文字型按钮） |
| 危险动作 | `#ef4444`，**必须带文字标签或 tooltip 明确说明** |
| 出现/消失 | 120ms 淡入；指针离开节点与工具条之间的安全区才消失，避免移动过程中闪烁 |

规则：**工具条按钮不超过 6 个**，超出收进 `⋯` 菜单。常用顺序：生成/重试 → 下载 → 复制 → 参考 → 更多 → 删除。

---

## 6. 连线锚点

- 锚点位于节点四边中点，默认隐藏，hover 节点或进入连线模式时显示。
- 命中热区 ≥ 16×16，视觉可以是一个 8px 圆点。
- 连线使用贝塞尔曲线；拖拽中实时跟随，松手吸附后可落入目标高亮。
- 连线颜色属于"关系"语义，应使用冰川蓝（`ice-500` / `#8cc7de`）；当前实现状态见 `DESIGN.md` 附录 A。

---

## 7. 节点内参数（轻量）

- 节点上只放**最常改的 1–3 个参数**（模型、比例或时长），全部参数在 `params-panel.md` 的面板里。
- 节点内控件高度 28px，字号 12px，与画布密度一致。
- 参数变化立即反映在元信息行，不需要"应用"按钮。

---

## 8. Do / Don't

**Do**

- 让内容占满节点，头部与元信息压缩到最小高度。
- 生成中只让描边呼吸，内容区显示骨架，不要旋转整个节点。
- 错误就地显示站点原文 + 重试，不弹窗。

**Don't**

- ❌ 给节点加卡片阴影或多层描边。
- ❌ 让图片节点按固定比例裁切（除非用户主动裁剪）。
- ❌ 在节点内塞完整参数面板。
- ❌ hover 工具条超过 6 个按钮。
- ❌ 用状态色（绿/黄）给节点描边上色。
