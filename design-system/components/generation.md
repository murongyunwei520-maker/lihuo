## 1. 生成是一次"提交 → 等待 → 落位"

三段式，每段的视觉职责固定：

| 段 | 用户看到什么 | 组件 |
|---|---|---|
| 提交 | 输入区（提示词 + 模型 + 参考图 + 生成按钮） | composer / config node panel |
| 等待 | 节点骨架 + 描边呼吸 + 阶段文案；任务条计数 +1 | node / task bar |
| 落位 | 结果就地出现在**发起它的那个节点** | node |

**结果必须落在发起节点上**，不允许落到"最新节点"或页面某处。这是画布产品最基本的因果契约。

---

## 2. 输入区（composer）

```
┌───────────────────────────────────────────┐
│ [参考图缩略] [参考图缩略] [+]              │  ← 参考图条，无图时折叠
│ ┌───────────────────────────────────────┐ │
│ │ 描述你想要的画面…                      │ │  ← 多行输入，自动增高（最多 6 行）
│ └───────────────────────────────────────┘ │
│ [模型 ▾] [比例 ▾] [时长 ▾]        [ 生成 ] │  ← 底部一行，32px
└───────────────────────────────────────────┘
```

| 项 | 规定 |
|---|---|
| 主按钮 | 全文唯一 primary：`生成`（12–13px，32px 高）。等待中变为 `取消` |
| 底部控件行 | 32px 高，控件间距 8px，左对齐；生成按钮贴右 |
| 输入框 | 无边框，底色随面板；聚焦时给 1px 雾霭紫描边，不加发光 |
| 参考图条 | 48px 缩略，圆角 8，右上角 16px 移除按钮；最多显示 4 个 + 计数 |
| 空提示词 | 生成按钮禁用（不允许"生成一个随机的"隐式行为） |

**窄容器降级**：当 composer 宽度不足时，模型/比例/时长的文字收起为纯图标 + tooltip（现有 `.canvas-composer-tools` 已实现容器查询，沿用同一策略，不要另写一套断点逻辑）。

## 3. 参考图与引用

| 类型 | 视觉 | 颜色 |
|---|---|---|
| 参考图（上传） | 缩略图 + 序号角标 | 中性 |
| 节点引用（`@` 提及） | chip：图标 + 节点名 | **冰川蓝**（`ice-50` 底 / `ice-600` 字） |
| 提示词片段 | chip：文本 | 中性或雾霭紫浅底（表示"用户自己的素材"） |

引用 chip 表达"这是一条关系（指向另一个节点）"，所以用冰川蓝；这跟"选中"（雾霭紫）是两个语义，不能混用。

引用被删除时 chip 立即失效并显示删除线 + 提示，不允许静默保留一个指向空节点的引用。

## 4. 等待态

| 时间 | 表现 |
|---|---|
| 0–300ms | 按钮 loading；节点出现骨架 + "排队中" |
| 300ms–30s | 节点描边呼吸；文案给阶段（"上传参考图"→"生成中"→"下载产物"） |
| > 30s | 同上 + 显示"可取消"；超过预期时长给"仍在生成，通常需要 1–2 分钟" |
| 有真实阶段信息时 | 显示阶段名而**不是**百分比 |

规则：

- **禁止假百分比进度条**。拿不到真实进度就用阶段 + 呼吸。
- **禁止在页面层再叠一个 loading**。节点已有骨架时不要再弹全局遮罩。
- 多个任务并行时，各自节点独立呼吸，任务条显示总数，**不弹 toast**。
- 视频必须先出首帧再显示播放控件；不允许先出现黑块。

## 5. 结果落位

| 内容 | 规则 |
|---|---|
| 图片 | 按原始比例贴合节点；不裁切、不拉伸；超出节点时等比缩小 |
| 多图 | 网格排列（2 张并排，3–4 张 2×2），标注序号；可切换主图 |
| 视频 | 首帧为封面，播放控件在 hover 时出现；不自动播放 |
| 音频 | 波形 + 播放按钮 + 时长 |
| 文本 | 保持可编辑，生成结果替换占位文本 |

落位动效：240ms 淡入 + 从 0.98 放大，只做一次，不回弹。

## 6. 失败与重试

- 错误**就地显示在节点内**，包含：站点/服务返回的原文（不翻译、不改写）、一句人话解释、重试按钮。
- 保留用户输入的提示词与参数，重试不需要重新填。
- 额度不足、未登录这类**需要用户去别处处理**的错误，额外给一个跳转入口（账号池 / 配置）。
- 批量生成部分失败时，成功的保留，失败的单独标红并可单独重试，**不要整批回滚**。

## 7. 图片二次编辑

| 操作 | 入口 | 规则 |
|---|---|---|
| 裁剪 | 图片工具条 | 进入独立编辑视图，画布其余部分变暗，`Esc` 返回 |
| 蒙版 | 图片工具条 | 蒙版叠加色用冰川蓝（当前为 `#2563eb`，待收敛） |
| 放大 | 图片工具条 | 显示倍率与目标尺寸；达到上限时禁用并说明原因 |
| 拆分 | 图片工具条 | 拆分结果作为新节点出现在原节点右侧，间距 24px |
| 角度 | 图片工具条 | 预设角度 + 自定义，实时预览 |

编辑视图统一：背景 `theme.canvas.background`，工具条沿用节点 hover 工具条的规格（48 / 18 / e1 阴影）。

## 8. Do / Don't

**Do**

- 生成按钮永远是这一屏唯一的 primary。
- 用阶段文案替代百分比。
- 失败保留输入，让重试成本接近 0。

**Don't**

- ❌ 结果落到错误节点或页面角落。
- ❌ 生成中弹 toast 或全局遮罩。
- ❌ 图片按固定比例裁切。
- ❌ 视频生成完自动播放（消耗流量、打断用户）。
- ❌ 把"额度不足"这类外部状态包装成"生成失败"。
