# TYPOGRAPHY.md · 字体与排版规范

离火只使用**系统字体栈**，不加载任何外部字体文件、不引入 `@font-face`、不新增字体依赖。

---

## 1. 为什么不用品牌定制字体

| 考虑 | 结论 |
|---|---|
| 中文正文字体文件动辄 3–8MB | 与"打开即用"的本地工作台定位冲突 |
| 字体商用授权链复杂 | 引入即产生法务负担，且无法在开源仓库里合规分发 |
| 系统字体在中文环境已足够好 | PingFang SC（macOS/iOS）、微软雅黑（Windows）覆盖绝大多数用户 |
| 品牌辨识靠图形与色彩 | 朱雀标志 + 雾霭紫，不依赖字形 |

> 参考资源 **Font in Logo** 在这里的作用只有一个：确认"品牌气质该往哪个方向靠"。它给出的字体名**不作为落地依据**，因为它不提供商用授权，只提供识别结果与置信度。详见 `references/02-fontinlogo.md`。

## 2. 字体栈（唯一标准）

```css
/* UI / 正文 / 标题 —— 全部共用 */
--font-sans:
    -apple-system, BlinkMacSystemFont, "Segoe UI", "PingFang SC",
    "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans SC",
    "Helvetica Neue", Arial, sans-serif;

/* 代码、JSON、提示词片段、模型名、坐标 */
--font-mono:
    ui-monospace, SFMono-Regular, "SF Mono", Menlo, Consolas,
    "Liberation Mono", "Courier New", monospace;
```

规则：

- **全站只有一个 sans 栈。** 标题与正文不换字体（`--font-heading` 与 `--font-sans` 同值），层级只靠字号、字重、颜色、间距区分。
- **中文必须显式列出** `PingFang SC` / `Microsoft YaHei` / `Noto Sans SC`，不能只靠拉丁字体回退，否则 Windows 会掉到宋体。
- **不用衬线体**做正文。品牌气质页（首页首屏、空态插画旁的大标题）可选宋体，但仅限短句、字号 ≥ 24px，不做中文正文。
- 代码与机器可读内容一律 mono：模型 ID、API 路径、JSON、任务日志、节点坐标、文件大小。

> 现状：`globals.css` 的 `@theme inline` 中 `--font-sans: var(--font-sans)` 是自引用，实际走 Tailwind 默认栈。这是**待收敛项**，收敛时按上面的栈显式声明，不要顺手改动其他变量。

## 3. 字阶

| 令牌 | 字号 | 行高 | 字重 | 用途 |
|---|---|---|---|---|
| caption | 11px | 1.4 | 400 | 辅助说明、时间戳、节点尺寸 |
| body-s | 12px | 1.4 | 400 | 画布面板正文、参数标签、表格次要列 |
| body | 13px | 1.5 | 400 | 后台正文、表单、下拉选项 |
| body-l | 14px | 1.6 | 400 | 长文阅读、帮助说明、空态描述 |
| title-s | 14px | 1.4 | 500 | 面板标题、节点标题、卡片标题 |
| title | 16px | 1.35 | 500 | 弹窗标题、区块标题 |
| title-l | 20px | 1.3 | 500 | 页面标题（后台）、抽屉标题 |
| display-s | 24px | 1.25 | 500 | 首页二级标题 |
| display | 30px | 1.2 | 500 | 首页主标题（移动端降为 24） |
| display-l | 38px | 1.15 | 500 | 首屏主视觉标题 |

约束：

- **画布内不使用 ≥ 20px 的字号**（节点内可选 12 / 13 / 14 / 16）。
- **后台不使用 ≥ 30px 的字号**，超过 24px 的标题只出现在登录页与空态。
- 字重只有 **400 / 500**。需要更"重"的视觉时，加字距或换颜色，不加 600/700。
- 全站不使用斜体表达强调；强调用颜色（雾霭紫）或字重 500。

## 4. 中西混排

| 场景 | 规则 |
|---|---|
| 中英之间 | 不手打空格。由浏览器字体度量自然分开，手打会出现不一致的缝 |
| 数字与单位 | 数字与单位之间加**半角空格**：`4 秒`、`12 MB`、`1920 px` |
| 中文标点 | 使用全角：`，。「」（）；：？！` |
| 英文与代码 | 保持原样，不加中文引号包裹；代码片段用 mono + 浅底 |
| 括号 | 中文语境用全角括号；纯英文内容用半角 |
| 破折号 | 中文用 `——`，英文用 `—` |
| 省略号 | 中文用 `……`，加载中文案用 `…`（三点，非六点） |

标点挤压：标点不出现在行首（`hanging-punctuation` 浏览器支持有限，靠文案长度控制即可，不做 hack）。

## 5. 数值排版

参数、时长、分辨率、价格、进度百分比统一：

```css
font-variant-numeric: tabular-nums;
```

场景：参数面板的滑杆数值、节点尺寸标注、任务时长、额度数字、表格中的数值列。

数值右对齐（表格列），单位左对齐并降一级颜色。例：

```
1920 × 1080 px
    12.5 秒
     4.2 MB
```

## 6. 文本截断与换行

| 场景 | 规则 |
|---|---|
| 节点标题 | 单行截断 + `title` 提示，不换行（换行会推挤节点内容） |
| 节点提示词 | 最多 3 行 `line-clamp`，超出省略，hover 看全文 |
| 表格单元格 | 单行截断，悬停显示完整内容；不允许行高随内容撑开 |
| 错误信息 | **不截断**，必须完整显示或提供"查看详情" |
| 中文段落 | 不设置 `word-break: break-all`，避免把词拆断 |

---

## 7. 画布 vs 后台

| 项 | 画布 | 后台 |
|---|---|---|
| 基准字号 | 12px | 13px |
| 标题字号 | 13 / 14px | 20px |
| 行高 | 1.4（紧凑） | 1.5（舒适） |
| 最大字号 | 16px（节点内容） | 24px（页面标题） |
| 标签位置 | 与控件同行（省纵向空间） | 控件上方（利于扫读与校验） |

---

## 8. Do / Don't

**Do**

- 用 `text-[12px]` / `text-[13px]` 这类精确值，而不是 `text-sm`（`text-sm` 是 14px，画布偏大）。
- 面板标题用 `14px / 500`，面板正文用 `12px / 400`，靠这一级差建立层级。
- 长提示词、JSON、模型名一律 mono。

**Don't**

- ❌ 不要引入 Google Fonts / 字体 CDN / 任何 `.woff2` 文件。
- ❌ 不要用 `font-bold`（700）表达"重要"，用颜色和间距。
- ❌ 不要在同一屏混用两种字体家族做标题与正文。
- ❌ 不要把中文正文做成衬线体或手写体。
- ❌ 不要在中文文案里手打中英空格制造"高级感"。
