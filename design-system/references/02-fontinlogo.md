# Font in Logo · 品牌字体参考

> 站点：https://www.fontinlogo.com/

## 一句话定位

品牌字体溯源数据库：收录 30k+ 知名 logo 与影视标题所用字体，并标注识别结果的**可信度等级**。

**它给的是"字体名 + 置信度"，不是字体文件，也不是商用授权。**

---

## 能学什么

1. **字体气质的分类型**：几何无衬线 = 现代/科技；过渡衬线 = 权威/编辑感；装饰体 = 类型化/娱乐。用于判断"离火该靠哪一档"。
2. **"logo 字体"多数不是现成字体**。这是最重要的一条认知：品牌字体常常是定制或改绘的。
3. **可信度分级本身就是教材**：同一个 logo 可能同时存在"确认""最接近""改绘""社区猜测"四种答案。
4. **免费字体的适用边界**：站内标注为 free font 的多是展示体（标题用），几乎都缺中文与正文能力。

## 不能学什么

1. ❌ **不能当排版规范。** 它不涉及字号、行高、字距、混排。
2. ❌ **不能当字体来源。** 站内的 "free font" 标签不等于可商用，必须自行核实授权。
3. ❌ **不能照抄品牌字体搭配。** 别人用装饰体是因为其行业属性，离火是工具型产品。
4. ❌ **不能据此引入任何字体文件。** 离火已定：纯系统字体栈，见 `TYPOGRAPHY.md`。
5. ❌ **不能把"最接近"当成"就是"** 去做品牌复刻。

## 可信度分级（站点原文口径）

| 标注 | 含义 | 可信度 |
|---|---|---|
| Verified | 站点设计师确认 | 高 |
| The Closest Font | 最接近的可用替代 | 中（**不等于原字体**） |
| Modified | 在原字体基础上改过 | 中 |
| Based On | 基于某字体重制 | 中 |
| Community Suggestion | 社区提交，未验证 | 低 |
| Community Designed | 社区根据 logo 反推设计，非实际使用 | 极低 |
| Display only | 仅用于展示，实际未内嵌该字体 | 参考 |

## 对离火的三个结论

1. **离火的品牌识别不建立在字体上。** 朱雀图形 + 雾霭紫 + 宣纸肌理已经足够，字体只承担可读性。这是刻意的选择，不是妥协。
2. **如果未来要做品牌字体**（例如官网大标题专用），方向应是**几何无衬线、字腔开阔、字重 500 左右**（参照 Cereal / Myriad 一档），而不是装饰体或手写体。且必须同时解决中文字形，否则中英混排会断裂。
3. **任何字体落地前必须先确认授权**，并在 `TYPOGRAPHY.md` 更新"字体栈"章节。在此之前，本文件不产生任何代码影响。
