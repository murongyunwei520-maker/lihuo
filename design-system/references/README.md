# references/ · 外部设计参考索引

这里记录离火**允许参考**的外部资源，以及**参考的边界**。

核心原则：**这些站点不是组件库，不是模板来源，不是可下载资产。** 它们各自只提供一种"判断"，被转译成离火自己的规范后才允许使用。

---

## 索引

| 文件 | 资源 | 唯一职责 | 服务于 |
|---|---|---|---|
| `01-landdding.md` | landdding.com | 整体视觉气质与首屏构图 | `DESIGN.md`、首页 / 登录 / 空态 |

## 访问与授权限制（必须如实标注）

| 资源 | 限制 |
|---|---|
| Landdding | 只有成品截图与站点链接，**无可下载文件、无代码、无 token** |
| Font in Logo | 只提供字体名与置信度分级，**不提供字体文件、不构成商用授权依据** |
| Jiro | 核心内容在**付费墙后**（$48 / 3 个月起）；MCP 需账号授权，本项目**未接入** |
| 60fps | 只有录屏视频，**无时长/缓动参数**，任何数值都是反推推断 |
| awesome-design-md | MIT 授权，可参考结构与写法；其中 token 来自对他人站点的 CSS 逆向，**数值不可搬用** |

因此本目录所有文档遵循同一写法：**写"可学什么"与"不可学什么"，不写"抄哪一段"。**

## 记录模板

新增参考时按此结构，不写日期：

```md
# 资源名

## 一句话定位
## 能学什么（≤ 5 条）
## 不能学什么（≤ 5 条）
## 具体条目与离火落点（表格）
## 使用建议
```

---

## 使用边界（写代码前必读）

1. **禁止像素级复刻。** 不允许把一个外部页面的布局、间距、文案照搬成离火的一屏。
2. **禁止搬运资产。** 不下载对方的图片、图标、字体、视频、代码。
3. **参考必须落到离火令牌。** 看到好的做法后，必须换算成离火已有的色值、间距、字号才能使用。
4. **记录来源。** 新增任何参考，必须在对应文件里写明出处与"我们改了什么"。
